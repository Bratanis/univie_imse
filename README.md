# About this project

This project was developed for the practical part of the "Information management and systems engineering" subject of the university of Vienna.
Started out as a group project, ended up being mostly a solo effort.

The premise is a simple gym membership web application that manages the data of users and gives insights to the gym administartors. The application also offers its users tutorials to help them with their workouts. The members can save the tutorials so they can view them later.

The idea was to create a database that can be accessed via a web front end. An admin can view all of the data and get special reports, while the users can only access their own data. For more information, please refer to the README.md file inside the "application" folder
